# SKY PREDICT 🌤️

Sky Predict is a futuristic weather intelligence web app designed to deliver live weather insights, smart forecasts, and AI-powered assistance in a sleek, immersive UI.

It combines real-time weather data, multi-day forecasting, climate trends, and an interactive JARVIS-style chatbot to make weather information feel more intelligent and engaging.

---

## Features

### 🌦️ Live Weather Insights
- Real-time weather data for searched locations
- Temperature, humidity, wind, precipitation, and pressure details
- Dynamic weather cards with current conditions

### 📅 Forecast Views
- 7-day weather forecast
- 6-month climate overview
- Visual charts for daily and monthly trends

### 🤖 JARVIS AI Assistant
- Interactive chatbot for weather-related questions
- Clothing recommendations based on conditions
- Travel and activity advice
- Smart responses for rain, heat, cold, and storm scenarios

### 🔔 Weather Alerts
- In-app alerts for rain, heat, cold, and storm warnings
- Browser notification support when allowed
- Alert prompts to keep users informed

### ✨ Futuristic UI
- Space-inspired glassmorphism design
- Animated starfield background
- Smooth intro screen and immersive dashboard layout

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/the-nidhi-bhat/sky-predict.git
   cd sky-predict
   ```

2. Open the project folder
   - You can simply open the folder in VS Code

3. Run the app
   - Open index.html in your browser
   - Or use a live server extension in VS Code

---

## Usage

- Type any city name in the search box to fetch weather data
- Switch between the 7-day forecast and 6-month climate view
- Open the chatbot to ask weather-related questions
- Enable alerts for helpful weather notifications
